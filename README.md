# Retail Sales Analysis Using Microsoft Excel

## Project Overview
This project focuses on analysing retail sales data using Microsoft Excel to identify sales trends, customer patterns, and business insights.

## Tools & Skills Used
- Microsoft Excel
- XLOOKUP and VLOOKUP
- Sorting and Filtering
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning and Analysis

## Project Objectives
- Analyse sales performance across product categories.
- Understand customer purchasing patterns.
- Compare sales across age groups and genders.
- Identify monthly sales trends.
- Present findings through an interactive dashboard.

## Dashboard Features
- Sales analysis by product category.
- Customer age-group analysis.
- Gender-wise sales distribution.
- Monthly sales trends.
- Interactive slicers for filtering data.
- Pivot charts for visual analysis.

## Key Insights
- Electronics recorded the highest sales among the product categories.
- Customers aged 26–35 represented the highest sales segment.
- The gender-wise sales distribution was approximately 49% male and 51% female in the initial analysis.

## Conclusion
This project helped develop practical skills in Excel data cleaning, data analysis, Pivot Tables, and interactive dashboard creation. It demonstrates how Excel can turn raw sales data into meaningful business insights.
